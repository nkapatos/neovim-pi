1. INTRODUCTION					*neovim-pi-introduction*

neovim-pi runs the Pi coding agent (https://github.com/earendil-works/pi) and
renders its state inside Neovim. Pi owns all agent state (sessions, models,
tools, approvals); Neovim paints what Pi reports and forwards user input.

This is an early implementation: version 0 is the package skeleton only. The
adapter and UI arrive in later iterations.

==============================================================================
2. REQUIREMENTS					*neovim-pi-requirements*

- Neovim >= 0.12.5.					*neovim-pi-nvim*
- The `pi` executable on `$PATH`.			*neovim-pi-pi*
- The experimental `ui2` module is used when available; otherwise the legacy
  messages and cmdline UI is used.

==============================================================================
3. INSTALLATION					*neovim-pi-installation*

Native package (|packages|). Clone into a `pack/*/start/` directory for
automatic loading: >sh
	git clone https://github.com/nkapatos/neovim-pi \
	  ~/.local/share/nvim/site/pack/core/start/neovim-pi
<
Alternatively install into `pack/*/opt/` and load it with |:packadd|: >vim
	:packadd neovim-pi
<

With the experimental |vim.pack| manager, add the following to your `init.lua`
and restart Neovim: >lua
	vim.pack.add({ 'https://github.com/nkapatos/neovim-pi' })
<

==============================================================================
4. COMMANDS					*neovim-pi-commands*

:Pi							*:Pi*
	Placeholder command. Reports whether the plugin loaded. Real agent
	commands are added in later iterations.

==============================================================================
5. HEALTH					*neovim-pi-health*

						*:checkhealth-neovim-pi*
:checkhealth neovim-pi
	Report the Neovim version, `ui2` availability, and whether `pi` is on
	`$PATH`.

==============================================================================
6. CONFIGURATION				*neovim-pi-configuration*

There are no user options yet. `require('pi').setup({})` is called
automatically when the plugin loads; calling it again is a no-op.
