1. INTRODUCTION					*neovim-pi-introduction*

neovim-pi runs the Pi coding agent (https://github.com/earendil-works/pi) and
renders its state inside Neovim. Pi owns all agent state (sessions, models,
tools, approvals); Neovim paints what Pi reports and forwards user input.

This is an early implementation. Neovim spawns `pi --mode rpc`, renders the
streaming transcript (assistant text, thinking, and tool calls) in a scratch
buffer, and provides a real input buffer to compose prompts. Pi owns all
session state; Neovim only renders what Pi reports.

==============================================================================
2. REQUIREMENTS					*neovim-pi-requirements*

- Neovim >= 0.12.5.					*neovim-pi-nvim*
- The `pi` executable on `$PATH`.			*neovim-pi-pi*
- The experimental `ui2` module is used when available; otherwise the legacy
  messages and cmdline UI is used.

==============================================================================
3. INSTALLATION					*neovim-pi-installation*

Native package (|packages|). Clone into a `pack/*/start/` directory for
automatic loading: >sh
	git clone https://github.com/nkapatos/neovim-pi \
	  ~/.local/share/nvim/site/pack/core/start/neovim-pi
<
Alternatively install into `pack/*/opt/` and load it with |:packadd|: >vim
	:packadd neovim-pi
<

With the experimental |vim.pack| manager, add the following to your `init.lua`
and restart Neovim: >lua
	vim.pack.add({ 'https://github.com/nkapatos/neovim-pi' })
<

4. COMMANDS					*neovim-pi-commands*

:Pi							*:Pi*
	Open the chat + input layout (chat on top, input below) and start
	`pi --mode rpc` in the current project directory if it is not already
	running. One Neovim instance maps to one Pi process.

:PiSend {text}					*:PiSend*
	Send a prompt to the running agent. Starts a session first if needed.

:PiAbort					*:PiAbort*
	Abort the current operation (also `<Esc>` in the chat buffer).

:PiModel					*:PiModel*
	Pick a model with `vim.ui.select` (built from `get_available_models`)
	and switch the running session to it.

:PiStop						*:PiStop*
	Stop the Pi process by closing its stdin (SIGTERM after a short grace
	period).

:PiStatus					*:PiStatus*
	Show plugin and session status.

The session statusline shows the current model, thinking level, and whether the
agent is idle or streaming.

==============================================================================
4a. INPUT BUFFER				*neovim-pi-input*

The input is a normal Neovim buffer (multi-line aware), not a one-line prompt:

- In insert mode, `<CR>` inserts a newline and `<C-s>` sends.
- In normal mode, `<CR>` sends.
- `<C-c>` returns to normal mode. `<Esc>` in the chat window aborts.

If your terminal swallows `<C-s>` (XOFF), use `<Esc>` then `<CR>` to send.

==============================================================================
5. HEALTH					*neovim-pi-health*

						*:checkhealth-neovim-pi*
:checkhealth neovim-pi
	Report the Neovim version, `ui2` availability, and whether `pi` is on
	`$PATH`.

==============================================================================
6. CONFIGURATION				*neovim-pi-configuration*

There are no user options yet. `require('pi').setup({})` is called
automatically when the plugin loads; calling it again is a no-op.
